RE4 JPN village dual-drop search v6
===================================

Purpose
-------
Search the supplied re4-wr-tas1.dtm for the two rewards generated by the first two village
Ganados killed by the same grenade.

Accepted target (either order):
  - Hand Grenade
  - 9900 ptas

Exact movie guard
-----------------
The search only starts with the supplied neutral movie:
  frame count: 8089
  input count: 16173

The in-memory snapshot is captured at movie frame 7823. The first mutable two-frame TAS slot is
F7826, which changes emulated frames 7825 and 7826. The search never changes the grenade throw or
the unsafe approach before frame 7825.

Automatic dual-drop calibration
-------------------------------
The neutral attempt is replayed twice. Both complete drop signatures must match exactly. From
those attempts, v6 discovers the two real drop-gate frames and shortens the mutation window to the
second gate. The search aborts if two deterministic drop events are not observed.

Target verification
-------------------
Hand Grenade is recognized at 0x800D1EF0 when r29 == 1.
Money is recognized at 0x800D2FE4 when r31 == 0x78. RE4 stores the amount in tens, so 9900 ptas
is accepted only when r29 == 990 (0x03DE).

Movement protection
-------------------
Leon runs forward through frame 7953 in the neutral movie. Mutations that can interrupt or slow
that run (L, R, B release, centered/negative Y) share a hard budget of four emulated frames per
attempt. Main-stick Y changes are never introduced after the optimized run. Camera/main-stick X
variations keep movement active, but the final winning movie should still be visually checked.

Search phases
-------------
Phase 0: two deterministic neutral validations.
Phase 1: single-slot probes across the automatically measured window.
Phase 2: coverage-guided mutation, editing, removal and splicing up to 200000 attempts.

Attempts containing only a Hand Grenade or only 9900 ptas are retained as high-priority parents.
The rarer 9900 parents receive the most search energy.

Output files
------------
Logs/re4_jpn_village_dual_drop_results.csv
Logs/re4_jpn_village_dual_drop_summary.txt
Logs/re4_jpn_village_dual_drop_FOUND.txt  (only on success)

When FOUND appears, send it together with the original neutral DTM. The listed plan can then be
applied byte-for-byte to create the final winning DTM.
